Cloud Security Specialist

  • Hae paikkaa

Tiivistelmä työpaikkailmoituksesta:

  • KPMG hakee Cloud Security Specialistia Cyber Advisory -tiimiin varmistamaan asiakkaiden pilvipalveluiden tietoturvaa erityisesti Microsoft-teknologioissa kuten Azure ja Microsoft 365.
  • Tehtäviisi kuuluvat pilviympäristöjen ja -palveluiden tietoturva- ja compliance-arvioinnit, tietoturva-arkkitehtuurien arviointi sekä asiakkaiden neuvominen parhaista käytännöistä.
  • Edellytämme kokemusta Microsoft Azuresta ja Microsoft 365 -palveluista, ymmärrystä tietoturva- ja compliance-vaatimuksista, soveltuvaa korkeakoulutaustaa sekä sujuvaa suomen ja englannin kielen taitoa, ja sertifikaatit kuten SC-500 ovat eduksi.
  • Tarjoamme vakituisen ja joustavan työpaikan kansainvälisessä asiantuntijaorganisaatiossa, toimipisteenä Helsinki tai Tampere, ja hakemukset tulee lähettää viimeistään 8.11.2026.


Tämä tiivistelmä on luotu tekoälyn avulla.

Me KPMG:llä uskomme, että yhteinen arvomaailma on avain työtyytyväisyyteen, kasvuun ja sitoutuneisuuteen. Kulttuurimme perustuu yrityksemme arvoihin. Toimimme rehellisesti, ajattelemme rohkeasti ja tähtäämme erinomaisuuteen. Arvostamme toisiamme ja työskentelemme yhdessä kohti parempaa.
 

Etsimme nyt Cloud Security Specialistia osaksi Cyber Advisory -ryhmäämme

Etsimme tiimiimme Cloud Security Specialistia, joka auttaa asiakkaitamme varmistamaan pilvipalveluympäristöjensä tietoturvallisuutta ja nostamaan pilvipalveluympäristöjensä tietoturvan tasoa. Tehtävässä työskentelet monipuolisissa asiakasprojekteissa keskittyen erityisesti Microsoft-teknologioihin, kuten Azureen ja Microsoft 365 -ympäristöihin.

Cloud Security Specialistina toimit asiantuntijana erilaisissa pilviturvallisuuteen liittyvissä toimeksiannoissa. Vastuisiisi kuuluu pilviympäristöjen ja -palveluiden tietoturvan arviointi, asiakkaiden neuvominen pilviturvallisuuden parhaista käytännöistä sekä sisäisten työkalujen ja menetelmien kehittäminen laadukkaiden projektitoimitusten varmistamiseksi. Projektit vaihtelevat lyhyistä arvioinneista pidempiin konsultointihankkeisiin.

Työskentelet tiiviissä yhteistyössä asiakkaiden sekä KPMG:n asiantuntijoiden kanssa. Yhteistyötä tehdään Cyber-tiimin lisäksi muiden tiimien osaajien ja kansainvälisten KPMG-kollegoiden kanssa.
 

Cloud Security Specialistina tehtäviisi kuuluu

  • Azure- ja Microsoft 365 -ympäristöjen tietoturvaratkaisujen arviointi ja näihin liittyvä konsultointi
  • Pilviympäristöjen tietoturva- ja compliance-arvioinnit
  • Tietoturva-arkkitehtuurien arviointi sekä suositusten laatiminen asiakkaille
  • Parhaiden käytäntöjen ja turvallisten toimintamallien määrittely asiakkaiden pilviympäristöihin

 

Toivomme sinulta

  • Kokemusta Microsoft Azure -ympäristöistä ja niiden tietoturvaratkaisuista
  • Osaamista Microsoft 365 -palveluista, kuten Purview’sta, Power Platformista, Copilotista ja AI-ratkaisuista
  • Ymmärrystä tietoturva- ja compliance-vaatimuksista sekä niiden soveltamisesta pilviympäristöihin
  • Kokemusta tietoturva-arvioinneista, konsultoinnista tai pilviarkkitehtuurien suunnittelusta
  • Asiakaslähtöistä työskentelyotetta ja hyviä vuorovaikutustaitoja
  • Tehtävään soveltuvaa korkeakoulutaustaa
  • Relevantteja sertifikaatteja, kuten SC-500; muut sertifikaatit, kuten SC-300, SC-401 tai vastaavat katsotaan eduksi
  • Työhön liittyvissä asioissa kommunikoit sujuvasti suomeksi ja englanniksi

 

Huomioithan, että asiakkaamme saattavat teettää toimeksiantoihin osallistuville henkilöille turvallisuusselvitykset (https://supo.fi/turvallisuusselvitykset).

 

Tarjoamme sinulle

Mielenkiintoisen ja monipuolisen työnkuvan suuressa kansainvälisessä asiantuntijaorganisaatiossa. Työskentelet kokeneiden ammattilaisten kanssa kannustavassa ja yhteistyötä arvostavassa ympäristössä, jossa vahva tiimihenki näkyy myös vapaa-ajan yhteisissä aktiviteeteissa.

Pääset osallistumaan monipuolisiin asiakasprojekteihin, jotka vaihtelevat laajuudeltaan, tavoitteiltaan, tuotoksiltaan ja asiakasorganisaatioiltaan. Tuemme jatkuvaa ammatillista kehittymistä koulutusten, konferenssien sekä käytännön projektikokemuksen kautta.

Pääset kehittymään niin teknisen osaamisen kuin liiketoimintaosaamisenkin saralla; Cyber-tiimissä kannustamme tiimiläisiämme luomaan innovatiivisia lähestymistapoja ja uusia ideoita sekä rohkeasti luomaan uudenlaista palvelutarjoamaa.

Työskentely meillä on joustavaa, ja KPMG tarjoaa monipuoliset henkilöstöedut sekä laaja-alaiset työhyvinvointia tukevat palvelut.

Tehtävä on vakituinen ja alkaa sopimuksen mukaan. Toimipisteesi sijainti voi olla joko Helsingin (Töölönlahdenkatu 3 A, 00100 Helsinki) tai Tampereen (Hämeenkatu 9, 33100 Tampere) toimistomme.
